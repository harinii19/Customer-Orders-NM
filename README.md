# Customer Orders Using Spring Boot

This is a Spring Boot application for managing customer orders. It provides functionalities to create, read, update, and delete customer orders, and stores data in a local SQLite database.

---

## Features
- Add new customer orders
- View existing orders
- Update order details
- Delete orders
- Persist data using SQLite database

---

## Technologies Used
- Java
- Spring Boot
- SQLite
- Maven

---

## Getting Started

### Prerequisites
- Java 23
- Maven

---

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JothiSri2005/Customer-Orders-Using-Spring-Boot.git

2. **Navigate to the project directory:**
   ```bash
   cd Customer-Orders-Using-Spring-Boot

3. **Build the project using Maven:**
   ```bash
   mvn clean install

4. **Run the application:**
   ```bash
   mvn spring-boot:run

---

## Usage
Once the application is running, you can access it at http://localhost:8080.

---

### Database
The application uses an SQLite database named customer_orders.db located in the project's root directory. Ensure that this file is present before running the application.
